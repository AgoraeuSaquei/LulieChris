# Luli & Chris — De volta para casa (edição de diálogos)

Jogo completo HTML5, sem editor nem instalação. Abra index.html ou publique todo o conteúdo na raiz do GitHub Pages. Substitua os arquivos anteriores, incluindo a pasta assets e o novo story.js. O progresso existente é preservado.

- levels.js: oito fases do JSON mais recente, posições e configurações preservadas; somente títulos, falas e dicas revisados.
- story.js: aberturas e conversas contextuais, uma vez por tentativa, quando a dupla está reunida e em segurança.
- assets/narrador: retratos próprios do narrador.
- assets/characters: sprites originais e expressões nomeadas.

Controles: setas/A/D, Espaço, Q (toque alterna, segure para estacionar a dupla, toque para reunir), E (conversar), P (pausa). Botões equivalentes no celular.
