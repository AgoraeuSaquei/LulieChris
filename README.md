# Luli & Chris — De volta para casa

Jogo final em HTML5/Canvas, sem editor, sem instalação e sem dependências externas.

## Jogar
Abra `index.html` no navegador. No computador, use setas/A/D, espaço, Q, E e P. No celular, use os botões de toque.

## Publicar no GitHub Pages
1. Envie o **conteúdo** desta pasta para a raiz do repositório (incluindo `assets/`, `levels.js` e `index.html`).
2. Em Settings > Pages, escolha Deploy from a branch, a branch principal e `/ (root)`. Salve.
3. Abra o endereço que o GitHub Pages disponibilizar.

O progresso de capítulos e preferência de som ficam no armazenamento local do navegador.

O arquivo `levels.js` contém as oito fases definitivas na ordem exportada. A geometria, as entidades e as configurações dos inimigos foram preservadas; títulos e falas foram revisados.
